# 🤖 Mini AI - Streamlit Chat Bot

Это красивое веб-приложение AI чат-бота на Python с использованием Streamlit и Claude API от Anthropic.

## ✨ Возможности

- 💬 Красивый веб-интерфейс
- 🧠 Сохранение контекста беседы
- ⚡ Быстрые ответы
- 🌐 На русском и английском языке
- 🎨 Современный дизайн с градиентом
- 📱 Адаптивный интерфейс

## 📋 Требования

- Python 3.8+
- Anthropic API Key

## 🚀 Установка и запуск

### 1. Клонируй репозиторий
```bash
git clone https://github.com/xumoramahmudova/mini-ai.git
cd mini-ai
```

### 2. Создай виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

### 3. Установи зависимости
```bash
pip install -r requirements.txt
```

### 4. Создай файл `.env`
```bash
cp .env.example .env
```

### 5. Добавь свой API ключ в `.env`
```
ANTHROPIC_API_KEY=your_api_key_here
```

Получить API ключ можно на https://console.anthropic.com/

### 6. Запусти приложение
```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## 🎯 Как использовать

1. **Вводи вопросы** в поле ввода внизу
2. **Смотри ответы** AI в реальном времени
3. **Используй боковую панель** для настроек и очистки истории
4. **Все сообщения сохраняются** в текущей сессии

## 🔧 Технологии

- **Python** - язык программирования

- **Anthropic Claude API** - AI модель

## 💡 Советы

- **Сохранить историю:** Скопируй текст из чата
- **Новый чат:** Нажми кнопку "Очистить историю" в боковой панели
- **API ключ:** Если ключ не в `.env`, введи его в боковой панели
